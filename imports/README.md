# Imports Staging Folder (`imports/`)

Drop or paste your past **Gemini web** chats and study notes into this folder!

### How to Export Notes from Gemini Web
1. **Option A (Fastest):** Copy the helpful responses from Gemini web and paste them directly into our Antigravity chat (or into a `.md` / `.txt` file inside this folder).
2. **Option B (Cleanest for long chats):** Click **Share & export → Export to Docs** in Gemini web, then in Google Docs click **File → Download → Markdown (`.md`)** and save the file here.

Once a file is here, tell Antigravity:
> *"Organize the files in `imports/` into my AI-901 study notes."*

*(Note: Anything placed inside `imports/private/` is automatically ignored by Git so raw drafts or personal notes stay strictly on your local computer.)*
